## Project layout

- Keep the single-file web app entry point at `index.html`.
- Keep project instructions in `AGENTS.md`, the specification in `spec.md`, and request history in `prompts.md` at the top level.
- GitHub Pages serves the top-level `index.html`.
- Save planning notes and sketches in `00_planning/`.
- Save hand calculations and test cases in `02_validation/`.
- Save screenshots and exported results in `03_output/`.
- Save new files in the folder that matches their purpose. Do not add new project folders or place planning, validation, or output files at the top level.
